# AGENTS Guidelines for This Repository

This repository contains a Kotlin Multiplatform application located in the root of this repository. It primarily targets iOS and Android, other 
multiplatform targets do not need to be considered. When working on the project interactively with an agent (e.g. GitHub Copilot) please follow 
the guidelines below.

## 1. Use the correct skill for the task
* Before changing code, inspect .github/skills/ and follow the relevant SKILL.md
* No matter what you do, always use the Skill "kmp-compose-multiplatform" and follow its guidelines
* If no Skill is appropriate, work according to the official Kotlin, Kotlin (Multiplatform) and Compose (Multiplatform) documentation and best 
  practices. Let me know what you were missing and suggest a new skill if necessary.
